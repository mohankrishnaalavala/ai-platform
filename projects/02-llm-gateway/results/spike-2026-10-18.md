# P2-01 spike: LiteLLM's open-source features, with no license key (2026-10-18)

**Question:** does LiteLLM's open-source proxy do every gateway must-have without a license key?
The must-haves are team keys, budgets, rate limits, revoking a key, fallback, PII masking and OpenTelemetry export.

## Method
- **Where:** GitHub Actions (`ubuntu-24.04` runner), branch `p2-spike`, workflow `p2-spike.yml`. There was no cloud login and no secrets. The master key and the Postgres password were random for each job, and masked.
- **Runs:**
  - Run 1: [39141058442](https://github.com/mohankrishnaalavala/ai-platform/actions/runs/39141058442)
  - Run 2: [39142668434](https://github.com/mohankrishnaalavala/ai-platform/actions/runs/39142668434). It was the same, with a 10 s `timeout` and `stream_timeout` on `chat-default`.
- **Config:** the exact configs and checks are at commit `1637649` on branch `p2-spike` (`projects/02-llm-gateway/spike/`, `.github/workflows/p2-spike.yml`). The raw output is in the runs' job logs and artifacts, which GitHub keeps for 90 days and 7 days; the lines below are copied from them.
- **Software, all pinned by digest:**
  - LiteLLM `ghcr.io/berriai/litellm-database:v1.103.3`, with **no license key set**
  - Presidio analyzer and anonymizer `2.2.362`
  - OpenTelemetry Collector contrib `0.161.0`
  - Postgres `17.6-alpine`
  - two mock providers (`python:3.13-slim`) standing in for vLLM and the hosted model. Each records every request body it receives.
- **Aliases:** `chat-default` goes to the vLLM mock and falls back to `chat-hosted`, which goes to the hosted mock. Test prices are $0.0001 per token, and each mock reply uses 60 tokens, so a call costs $0.006.
- **Two masking variants:**
  - **all:** the Presidio guardrail is `default_on: true`, so it masks every request
  - **hosted-only:** a config policy attaches the guardrail to `chat-hosted` only
- **Test data:** the PII is fake: `jane.doe@example.com`, `212-555-0143`, `4111 1111 1111 1111`, `Jane Doe`.

## Results (run 2)
| Check | all | hosted-only |
|---|---|---|
| Team budget $0.01 | 2 calls OK, then HTTP 429 `budget_exceeded` (cost 0.012) | same |
| Team RPM limit 2 (5 calls) | 200, 200, 429, 429, 429 | same |
| Revoked key (`/key/delete`) | 200 before, 401 after | same |
| PII on `chat-hosted`, plain and streaming | masked (`<PERSON>`, `<EMAIL_ADDRESS>`, `<PHONE_NUMBER>`, card) | masked |
| PII on `chat-default` to vLLM | masked | not masked (by design of this variant) |
| Fallback with the vLLM mock stopped | answered by the hosted mock, 10,925 ms plain, 11,000 ms streaming; header `x-litellm-attempted-fallbacks: 1` | answered by the hosted mock, 10,966 ms and 10,995 ms |
| **PII on the fallback** | **masked** | **raw email, phone, card and name reached the hosted mock** |
| Raw PII in the gateway log and the traces | 0 | 0 |
| Spans received by the collector | 169 | 142 |
| Spend-log rows / rows with raw PII | 15 / 0 | 15 / 0 |
| License, premium or enterprise messages in the gateway log | none | none |

## What run 1 showed
- **No timeout on `chat-default`:** with the vLLM mock stopped, a request was still waiting after 60 s and never fell back. The hosted mock got no request.
- **Presidio slow to start:** on one of the two runners, the analyzer was not healthy within 300 s. In run 2 it was healthy in about a minute on both runners.

## Hosted model on Vertex AI (same day, as the project owner)
- **Claude Haiku 5.5** (`claude-haiku-5-5`, global endpoint): HTTP 429 `RESOURCE_EXHAUSTED`, because the project's Claude quota is 0. A request to raise it was denied within minutes, on all three quotas: 10 requests a minute, 20,000 input tokens a minute and 5,000 output tokens a minute.
- **Gemini** (`gemini-3.5-flash-lite`, global endpoint): one keyless call, HTTP 200, 8 tokens in total.

## Conclusion
- **Every must-have works with no license key.**
- **Mask all traffic:** a guardrail scoped to the hosted model misses requests that fall back to it.
- **Set a timeout:** `chat-default` needs an explicit timeout, or a dead upstream holds requests instead of falling back.
- **Hosted model:** Gemini on Vertex AI, keyless, because Google denied the Claude quota.
